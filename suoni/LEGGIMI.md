# Suoni dei sorpassi

Carica qui i tuoi video o audio (mp4, mov, webm, mp3, m4a, wav, ogg).

- Ad ogni sorpasso, sul telefono di chi sorpassa parte l'audio di uno di questi file.
- L'ordine è casuale: ogni file suona una volta, poi si rimescola e si ricomincia.
- Se la cartella è vuota, la Coppa Gyoza usa le sue musiche e telecronache.
- Tieni i file sotto i 25 MB (limite del caricamento da sito di GitHub). Clip corte di 5-15 secondi funzionano meglio.
- I nuovi file arrivano sui telefoni entro circa 15 minuti.
